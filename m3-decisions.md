# MB Decisions
## AI Defense
The AI CSS has 32 rules, while my CSS has 17. The AI CSS has more styles, so it looks more detailed.
The AI uses `nav a:hover::after` for the navigation effect.
Both CSS files have 0 `!important`.
The AI CSS has more direct colors, but it also uses color variables.
At 320px, the AI CSS has a media query. It changes the header, navigation, heading, and spacing. My CSS does not have this.
The AI CSS also has some color problems. For example, white text on `#e63946` has a 4.17:1 ratio, which is below 4.5:1.
## What I Accepted
I accepted the mobile layout idea because my CSS does not have one.
I also accepted the color change because white text on hotpink had a 2.65:1 ratio.
## What I Rejected
I did not copy the whole AI CSS because I already have my own colors, spacing, and text sizes.
I also kept my CSS simple.
## Improvements
I added a mobile layout for smaller screens.
I also changed my main color to make the text easier to read.
I made a separate commit for each change.
